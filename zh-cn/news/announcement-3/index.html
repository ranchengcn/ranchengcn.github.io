EvoGit荣获AgentX国际竞赛多智能体系统赛道全球冠军

发布于 2025年08月07日

2025

我们的项目 EvoGit 荣获 AgentX国际竞赛多智能体系统赛道全球第一名。AgentX由加州大学伯克利分校主办，得到 Google、Amazon 和 Hugging Face 等科技公司的支持，是推动大语言模型（LLM）智能体技术发展的重要国际平台。

AgentX — LLM Agents MOOC Competition（2025年春季）概况

本次竞赛吸引了来自全球 100多个国家、800所高校的近1,000支队伍，其中包括加州大学伯克利分校、斯坦福大学和卡内基梅隆大学等知名高校。经过来自 Google DeepMind、Meta FAIR、NVIDIA 等机构的28位专家多轮评审，最终仅有 15支队伍晋级线下决赛展示环节（Demo Day）。

来自香港理工大学数据科学及人工智能学系的团队，是唯一晋级决赛的中国团队（含港澳台地区），并凭借 EvoGit 在技术挑战最为突出的多智能体系统赛道摘得桂冠。

EvoGit将代码演化过程组织为有向无环图（DAG），让多个智能体协同演化、持续开发。

EvoGit 是一个去中心化多智能体框架，将软件开发视为持续演化的过程。它以 Git 提交构成的有向无环图（DAG）描述开发过程：多个智能体独立提出增量代码修改或结构性交叉方案，无需依赖中心化调度器或显式通信协议即可开展协作。

这种架构使智能体具备自组织、可扩展和稳健协作的能力。依托标准 Git 基础设施，EvoGit也支持顺畅的人机协作，让开发者通过熟悉的版本控制工具检查、干预并共同推进开发。

EvoGit为构建可演化的大语言模型智能体迈出了重要一步，使智能系统能够随时间自主改进自身的结构与行为。
