我们的项目 **EvoGit** 荣获 [**AgentX国际竞赛**](https://rdi.berkeley.edu/agentx/)**多智能体系统赛道全球第一名**。AgentX由**加州大学伯克利分校**主办，得到 **Google、Amazon 和 Hugging Face** 等科技公司的支持，是推动大语言模型（LLM）智能体技术发展的重要国际平台。

![AgentX竞赛概况](https://www.polyu.edu.hk/dsai/-/media/Department/DSAI/Media-Release/2025/01-08/News_20250807_Picture2r.png?rev=3c9e21edc3164f24bc27fca2b97d9e54&hash=90523A5004FA39F4CB8CB0269087C3A1)

_AgentX — LLM Agents MOOC Competition（2025年春季）概况_

本次竞赛吸引了来自全球 **100多个国家、800所高校的近1,000支队伍**，其中包括加州大学伯克利分校、斯坦福大学和卡内基梅隆大学等知名高校。经过来自 **Google DeepMind、Meta FAIR、NVIDIA** 等机构的28位专家多轮评审，最终仅有 **15支队伍**晋级线下决赛展示环节（Demo Day）。

来自香港理工大学数据科学及人工智能学系的团队，是**唯一晋级决赛的中国团队（含港澳台地区）**，并凭借 **EvoGit** 在技术挑战最为突出的多智能体系统赛道摘得桂冠。

![EvoGit多智能体协同演化框架](https://www.polyu.edu.hk/dsai/-/media/Department/DSAI/Media-Release/2025/01-08/News_20250807_Picture6r.png?rev=eee08fefdc4b4f96a14702074db39526&hash=07BC381335F88EAF081B06E748EC0B20)

_EvoGit将代码演化过程组织为有向无环图（DAG），让多个智能体协同演化、持续开发。_

**EvoGit** 是一个去中心化多智能体框架，将软件开发视为持续演化的过程。它以 Git 提交构成的**有向无环图（DAG）**描述开发过程：多个智能体独立提出增量代码修改或结构性交叉方案，无需依赖中心化调度器或显式通信协议即可开展协作。

这种架构使智能体具备**自组织、可扩展和稳健协作**的能力。依托标准 Git 基础设施，EvoGit也支持顺畅的人机协作，让开发者通过熟悉的版本控制工具检查、干预并共同推进开发。

EvoGit为构建**可演化的大语言模型智能体**迈出了重要一步，使智能系统能够随时间自主改进自身的结构与行为。
