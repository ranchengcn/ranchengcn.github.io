Our team at PolyU won first place in the multi-agent track at Berkeley’s AgentX competition. I worked on EvoGit with PhD student Beichen Huang and my colleague Kay Chen Tan. [Competition results](https://rdi.berkeley.edu/agentx/)

In EvoGit, a group of coding agents works on a shared Git repository. Each agent can pick up another agent’s commit, try a change, or combine ideas from two branches. The commit history lets us trace how a piece of code developed and see which agent contributed each change.

![EvoGit agents building on and combining Git commits](https://www.polyu.edu.hk/dsai/-/media/Department/DSAI/Media-Release/2025/01-08/News_20250807_Picture6r.png?rev=eee08fefdc4b4f96a14702074db39526&hash=07BC381335F88EAF081B06E748EC0B20)

We tried EvoGit on two tasks. In one, the agents built a web application from an empty repository. In the other, they wrote a program that could itself develop and test solutions to a bin-packing problem. [EvoGit paper](https://arxiv.org/abs/2506.02049)
